# پیش‌نمایش رابط پلاکینو

تصاویر از اجرای واقعی رابط Kivy با اندازهٔ ۱۲۰۰×۷۸۰ گرفته شده‌اند. داده‌های داشبورد در این تصاویر نمونهٔ ثابت برای بررسی ظاهر هستند؛ تصاویر، اتصال زندهٔ دوربین یا صحت OCR را اثبات نمی‌کنند. هیچ تصویر نامرتبطی به پلاک‌های نمونه نسبت داده نشده است.

- `dashboard.png`: طرح HTML با نمودار ورود هفتگی، آخرین شناسایی‌ها، چهار کارت و منوی چهارگزینه‌ای.
- `login.png`: لوگوی یکسان، فرم ورود و نورهای آبی و بنفش.
- `ticket.png`: نتیجهٔ ثبت تیکت نمایشی، بدون ارسال خارجی.

علت دو ایرادی که هنگام انتقال طرح رفع شدند: Kivy کلید سازندهٔ `on_navigate` را اتصال رویداد تعبیر می‌کرد و مقدار callback منو خالی می‌ماند؛ همچنین خواندن `right/top` در callback تغییر اندازه، مختصات کش‌شدهٔ قبلی را به حاشیهٔ گرادیان می‌داد. آزمون‌های رابط هر دو مسیر را پوشش می‌دهند.
