# Enterprise UI refinement

Rendered Kivy screens at 1200 × 780. Dashboard values and events are fixtures; camera streaming is disabled for these captures. Empty and error captures exercise the existing dashboard presentation callback. No external service was connected.

The existing navigation and dashboard panel order are preserved. The refinement replaces neon frames and animated background lights with graphite surfaces, muted accents, consistent Lucide icons, larger secondary text, thin borders and fast interaction feedback. Iranian plate layout is unchanged.

Validation: 8 UI contract tests (including navigation, compact/large desktop layout, ticket interaction and primary-button contrast), plus 2 Iranian plate tests passed. Screens were visually checked for login, dashboard, monitoring, settings, empty and error states.
